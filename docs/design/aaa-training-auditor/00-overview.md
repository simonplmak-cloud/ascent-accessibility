# 00 — Overview

Ascent Accessibility redesign: two product surfaces over the existing assessment
engine, with **utilization and efficiency** as the north star.

## Objectives

1. **Professional training** — a free, structured, self-paced learning path
   (path → module → lesson → quiz → downloadable PDF certificate). No paywall;
   progress/credentials require sign-in.
2. **Auditor workspace** — a re-organized, efficiency-focused workspace for
   professional auditors: assessment queue, review, evidence, and one-click
   **PDF** report download (the only report export format).

## Personas

| Persona | Needs | Efficiency signal |
|---|---|---|
| Learner | understand WCAG, track progress, earn a PDF certificate | "Continue learning" resume, explicit fractions |
| Auditor | scan sites, review "Cannot tell" SCs, produce reports fast | bulk resolve, saved views, ⌘K, one-click export |
| Admin/reviewer | manage the review workforce queue | queue health dashboard |

## Success metrics

- **Time-to-report** — from scan to a shareable PDF report in the fewest steps.
- **Keyboard coverage** — every primary workflow completes without a pointer.
- **Resume rate** — learners return to the exact lesson, not the path start.
- **Orphan-free** — no dead route/component after the refactor (see 07 ledger).

## Non-goals

- No LMS machinery (instructors, cohorts, grading queues, SCORM).
- No new client/engagement tables (auditor reuses existing assessment/evidence/review).
- No paywall, no new third-party auth/credentialing.
